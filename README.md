# Sales Data Analytics

A SQL-based retail sales analytics project built using SQLite and Python. It analyzes customer behavior, product performance, revenue trends, and business operations.

## Features
- Customer and product analysis.
- Total and monthly revenue reports.
- Top-selling product identification.
- Customer spending analysis.
- Category and payment method analysis.
- Average order value calculation.
- SQL joins, subqueries, CTEs, and window functions.

## Technologies
- SQL
- SQLite
- Python
- VS Code

## How to Run

```bash
python database.py
```

Choose option 1 to create the database and insert sample data.

Choose option 2 to execute the SQL analytics queries.

## Database Tables
- Customers
- Products
- Orders
- Order Items

## Purpose

Demonstrates practical SQL skills through retail sales data analysis and business-oriented queries.
